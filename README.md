# django_site
Необходимое ПО: Docker Desktop (Windows/macOS) или Docker Engine + Compose (Linux)
Запустите Docker
Через консоль зайдите в каталог mysite и введите: docker compose up --build
Через 10-15 секунд (в зависимости от скорости интернета может потребоваться больше времени) в адресной строке браузера введите: http://localhost:8000
